# Modular AI v0.3
Optional on-device pretrained SmolLM2 135M (q8) or 360M (q4) via pinned Transformers.js CDN. Original custom TypeScript engine preserved; explicit arithmetic, conversion, memory and summary requests use original skills. Language model downloads on first conversational request, runs in a worker, and keeps recent turns in session memory. Model outputs are not verified. No inference API or server. External library/model downloads are not covered by the original custom skill SHA-256 manifest. Actual model inference requires a supported browser, available memory and network for first download. The 135M model is limited and may hallucinate. The 360M model requires substantially more memory. Test with Wi-Fi and compare modes.
