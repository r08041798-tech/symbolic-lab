What counts as correct?

A positive result needs a stored proof path. A negative result needs explicit negative evidence or a known counterexample. Otherwise it returns unknown.

Can it write creatively?

Try “Write about rain and hope.” Its limited compositional generator connects stored relations using predefined language rules.

Important

This is a research prototype, not a general language model. Facts you teach are marked as user assertions, not independently verified truth.

Research a new concept

The engine searches Wikidata, not the whole internet. Choose a specific entity, and it imports mapped relationships, category chains, dates, and provenance. No AI service is contacted.

Sourced ≠ verified. Wikidata is collaboratively edited. We preserve QIDs and links but cannot independently certify every imported claim. Ambiguous names must be selected explicitly.

Memory notice

Free hosting has temporary server storage. Your browser remembers up to four topic QIDs and attempts to research them again after a server restart, within rate limits.

Test learning

First ask “Is a robin an animal?” It should say unknown. Teach “A robin is a bird”, then ask again. It should infer robin → bird → animal.

Behavioral evaluation

Run a fixed reference suite with transitive reasoning, negative evidence, unknown questions, language patterns and creative composition. It measures behavior, not scientific proof of intelligence.
